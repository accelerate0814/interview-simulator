## 0. 定位（frontend-design：先钉死主体）

- **主体**：一个人独自练面试的工具。用户多为技术/知识岗求职者，紧张，练习时只有自己。
- **单一任务**：逐题跑一场模拟面试，结束后给一份打了分的复盘。
- **不是**：落地页、不是 wellness app、不是考试系统。

## 1. 设计概念：「录音棚 / The Booth」

坐下 → 指示灯亮 → 你开始表现 → 结束后回放这盘带子。
克制、低噪、专注，带一点「仪器感」。既有沉稳（顾问），也有「这是玩真的」（不是玩具）。

**主动避开 frontend-design 点名的三套 AICSS 套路**：
1. 米白 + 高对比衬线 + 赤陶 —— 上一版就是这个，弃。
2. 近黑底 + 单一荧光绿/朱红 —— 弃。
3. 报纸发丝线 + 零圆角 + 密排栏 —— 弃。

分工：**蓝 = 结构 / 动作 / 信任；琥珀 = 你正在直播、这是实时的**。琥珀绝不用作普通装饰。

### 字体（真配对，不是单字体，不用 Inter）

```
--font-display: 'Fraunces', 'Songti SC', Georgia, serif;   /* 有性格的旧式衬线，opsz 轴，克制使用，只用 roman */
--font:         'IBM Plex Sans', 'PingFang SC', 'Microsoft YaHei', system-ui, sans-serif;  /* 人文无衬线，正文/UI */
--mono:         'IBM Plex Mono', 'SF Mono', Consolas, monospace;  /* 计时、分数、轮次、标签、kbd —— 「仪器」嗓音 */
```

- Plex Sans + Plex Mono 同族 → 系统内聚；Fraunces 是唯一有性格的外来者，稀用（欢迎页 H1、浮层标题、复盘大标题）。
- 标题一律 roman（`font-style: normal`）—— 斜体标题是头号 AI tell（hallmark 硬规则）。
- 字号刻度：display `clamp(30px, 4.2vw, 42px)` / 大标题 20 / 卡片标题 16 / 正文 15 / 注释 12.5 / mono 标签 10.5。
- 行高：正文 1.75，长题目阅读 measure ≤ 68ch。

### 间距 / 圆角 / 阴影

- 4pt 网格，语义名：`--space-2xs 4 / --space-xs 8 / --space-sm 12 / --space-md 16 / --space-lg 24 / --space-xl 32 / --space-2xl 48`。
- 圆角克制：`--radius-sm 6 / --radius-md 10 / --radius-lg 16 / --radius-full 999`。比上一版（9/14/20）更收，去「糖果感」。
- 阴影：单层、低扩散、冷向。`--shadow-sm` 发丝、`--shadow-md` 浮层、`--shadow-lg` 大浮层。
- 动效：标准 `--dur 160ms --ease cubic-bezier(.2,0,0,1)`；浮层/欢迎 240ms 上浮；状态条呼吸 2.8s。`prefers-reduced-motion` 全量降级为 ≤120ms 淡入、去除呼吸。
- `:focus-visible`：2px `--blue` 实心环 + 2px offset，出现瞬间无动画。

### 签名元素：状态条（status rail）

聊天列左缘一条 3px 竖条，用纯 CSS `:has()` 跟随会话状态，**app.js 零改动**：

- 未开始：透明。
- 进行中：`--ember` 实心，顶部 40px 缓慢呼吸（tally 灯）。
- 暂停：`--ember` 虚线、不呼吸。
- 已结束：转 `--blue` 实心、不呼吸（「这条带子录完了，去回放」）。

把计时、轮次、直播态收进屏幕边缘一个「有实体感」的物件。这是全站唯一记忆点，其余一律安静。

## 4. 逐屏视觉规范（imagegen-frontend-web 规则集，文字版；每屏一段，不是一张图）

统一：暖纸灰底，蓝墨主色，琥珀只标「进行中」，Fraunces 大标题 + Plex Sans 正文 + Plex Mono 数据。发丝线分隔，圆角克制，留白大。全站一个调，不逐屏换主题。

### 屏 1 · 侧栏（常驻）
锚点：左对齐纵向列。宽 ~260px，`--sunken` 底，右缘一条 `--line`。
顶部：mono 小写「面试模拟」字标 + 一个描边圆点 logo（琥珀）。下面「新的一场」主按钮（蓝墨实心、胶囊、不浮起）。
分组用 mono 全大写 10.5px 极小标签 + 发丝线，不用卡片盒子。历史记录占弹性高度可滚；活动条目左缘一条 2px 琥珀书脊（正在进行的那场）或蓝墨书脊（历史选中）。
「这场面试」：一个横排读数器 —— 用时 `MM:SS`（mono，进行中琥珀）｜已答 N。点一下暂停，暂停时数字转灰、旁边出「已暂停」mono 角标。
底部工具行：5 个描边线性图标按钮（语音播报 / 深色模式 / 我的资料 / 我的题库 / 模型配置），无 emoji。

### 屏 2 · 欢迎首屏（会话未开始）
锚点：左对齐编辑块，垂直居中，max-width ~560px，**不居中对齐、不加径向光晕**。
mono overline「练习，然后再上场」→ Fraunces 大标题两行「把面试当练习，／一题一题过。」（roman，字重 500，行高 1.2，字距 -0.01em）→ 一段 Plex Sans 正文（`--ink-soft`，measure ~46ch）→ 蓝墨主 CTA「开始面试」（唯一允许 hover 上浮 2px 的元素）→ 一条 `--line` 细横线 → 一行 mono `--ink-faint` 点分隔能力点。
背景：纯 `--paper`，右下角可有一枚极淡的描边同心圆做「靶心」母题（`--line` 色，10% 透明，装饰但有结构含义 = 目标/岗位）。

### 屏 3 · 开始前浮层
锚点：居中卡片 max-width ~440px。Fraunces 标题「开始前，选一份参考资料」+ 副文。
两个字段：简历（复选框，未上传则禁用并给出指路文案）｜岗位 JD（下拉）。
主按钮「按所选资料开始」蓝墨实心；次按钮「用通用题库开始」描边（明显次级）；「取消」纯文字。

### 屏 4 · 面试进行中（聊天）
锚点：单栏阅读流，max-width ~680px 居中，左缘 3px 琥珀状态条 + 顶部呼吸。
面试官发言：**不用气泡**——一个 mono 小标「面试官」+ 下面正文（Fraunces 不用于正文，仍是 Plex Sans，15px/1.8，`--ink`）。
你的发言：右对齐，`--blue-tint` 底、克制圆角块，max 80% 宽。
流式光标：琥珀 `▍` 闪。
输入区：一条 `--surface` 合成条，`--line-strong` 边，聚焦时蓝墨环 + 4px wash。右侧麦克风 + 发送两个图标按钮，发送为蓝墨实心。下面 mono 提示行。录音时麦克风转琥珀并轻脉冲，输入区上方出「正在听你说」+ 琥珀点。

### 屏 5 · 面试结束条
状态条转蓝墨。底部一条 `--surface` 横条：Fraunces「这场面试结束了」+ 蓝墨按钮「生成复盘报告」。输入区隐藏。

### 屏 6 · 复盘浮层
锚点：大浮层 90vw / max 860 / 88vh。
头部：Fraunces「面试复盘」+ 右侧「下载 Word」描边、「关闭」描边（危险色）。
Meta 行：4 项 —— 岗位 / 层级 / 综合评分（大号 mono `N/10`）/ 结论（badge，按结论取色，不用刺眼纯色）。
「逐题回顾」：每题一张卡 —— 卡头 `Q1`（mono，蓝墨）+ 题干（Plex Sans 600）+ 该题分（mono）。卡体三段：你的回答（`--ink-soft`）｜参考答案（`--green-tint` 底，绿边，这是唯一的绿区）｜点评。
「总体评价」：三卡网格 —— 做得好的 / 可以更好的 / 建议补的，破折号列表。
加载态：一个细环 spinner + 「正在整理这场面试的复盘」。

### 屏 7 · 我的资料 / 模型配置 / 我的题库（共用浮层壳）
锚点：居中面板 460px（题库 560）。
统一头部：Fraunces 标题 + 描边关闭。表单：mono 极小标签 + `--sunken` 底输入 + 聚焦蓝墨环。主操作蓝墨实心、次操作描边。状态行居中、成功用绿字（不用 ✓ 字符）。
题库：虚线上传区（hover 蓝墨）；类别 chip 带真实计数；题目卡 = 题干 + 点分隔出处 meta（类别 tag / 公司岗位 / 来源文件）+ hover 出删除；诚实空状态；分页。整篇兜底项用琥珀虚线边框（这是「未处理」信号，符合琥珀=进行中/待办的语义）。
